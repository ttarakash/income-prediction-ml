# Прогноз уровня дохода (машинное обучение)

Бинарная классификация: зарабатывает ли человек больше $50 000 в год, по демографическим и трудовым признакам. Финальный проект курса Big Data and Neural Networks (AUCA).

## Данные
- Adult Census Income (U.S. Census Bureau): 48 842 наблюдения, 15 признаков.
- Значения `?` обработаны как пропуски, строки с ними удалены. Осталось **45 222** наблюдения.
- Целевая переменная: доход >50K у 24,8% людей.
- Данные в репозиторий не включены. Чтобы запустить тетрадь, положите `adult.csv` в папку `data/`.

## Что сделано
1. **Очистка:** поиск скрытых пропусков (`?`), удаление неполных строк, кодирование целевой переменной.
2. **EDA:** распределение возраста, доход по уровню образования, корреляции числовых признаков.
3. **Подготовка:** one-hot кодирование категориальных признаков; разбиение 70/30 со стратификацией.
4. **Модели:** логистическая регрессия, дерево решений, Random Forest.
5. **Оценка:** accuracy, precision, recall, F1, ROC-AUC, ROC-кривые, матрица ошибок.

## Результаты (тестовая выборка)

| Модель | Accuracy | Precision | Recall | F1 | ROC-AUC |
|---|---|---|---|---|---|
| Логистическая регрессия | 0,838 | 0,719 | 0,568 | 0,635 | 0,884 |
| Дерево решений | 0,849 | 0,758 | 0,574 | 0,653 | 0,893 |
| **Random Forest** | **0,853** | **0,783** | 0,564 | **0,655** | **0,913** |

## Выводы
- Лучший результат по большинству метрик и по ROC-AUC (0,913) у Random Forest.
- Recall у всех моделей около 0,57: примерно 43% людей с высоким доходом модели относят к низкому. При необходимости это можно поправить порогом классификации или весами классов.
